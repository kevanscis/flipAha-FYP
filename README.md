# FlipAha - Math Tutor Application

A modern web application with a **Python Flask** backend and **React + Vite** frontend for interactive math tutoring.

## Project Structure

```
flipAha-FYP/
├── app.py                      # Flask backend
├── requirements.txt            # Python dependencies
├── .env                        # Environment variables (optional)
├── frontend/
│   ├── index.html             # HTML entry point
│   ├── vite.config.js         # Vite configuration
│   ├── package.json           # Node dependencies
│   ├── .env                   # Frontend environment variables
│   └── src/
│       ├── main.jsx           # React entry point
│       ├── App.jsx            # Main App component
│       ├── index.css          # Global styles
│       └── components/
│           ├── ChatMessage.jsx
│           ├── MessageInput.jsx
│           ├── ChatMessage.css
│           └── MessageInput.css
└── README.md
```

## Setup Instructions

### 1. Install Python Dependencies (Backend)

```ensure you are in flipAha-FYP folder```
```bash
pip install -r requirements.txt
```

### 2. Install Node Dependencies (Frontend)

```bash
cd frontend
npm install
```

### 3. Run the Flask Backend

```bash
python app.py
```

The backend will start on `http://localhost:5000`

### 4. Run the React Frontend (in a separate terminal)

```bash
cd frontend
npm run dev
```

The frontend will start on `http://localhost:5173`

## Environment Configuration

### Frontend `.env`
The frontend uses an environment variable to configure the API URL:

```env
VITE_API_BASE_URL=http://localhost:5000
```

This is referenced in `src/App.jsx`:
```javascript
const API_BASE_URL = import.meta.env.VITE_API_BASE_URL
```

## API Endpoints

### POST `/api/questions`
Sends a math question and receives a response.

**Request:**
```json
{
    "question": "What is the derivative of x²?"
}
```

**Response:**
```json
{
    "success": true,
    "question": "What is the derivative of x²?",
    "answer": "To find the derivative of x²...",
    "topic": "derivative"
}
```

### GET `/health`
Health check endpoint.

**Response:**
```json
{
    "status": "ok"
}
```

### CORS Configuration
The backend allows requests from `http://localhost:5173` (development frontend). Headers include:
- `Access-Control-Allow-Origin: http://localhost:5173`
- `Access-Control-Allow-Methods: GET, POST, OPTIONS`
- `Access-Control-Allow-Headers: Content-Type, Authorization`

## Features

- **Interactive Chat Interface**: Real-time math tutoring with message history
- **Question Classification**: Automatically identifies math topics from questions
- **Hardcoded Responses**: Provides educational responses for multiple math domains
- **Responsive Design**: Works on desktop and mobile devices
- **Theme Color**: Modern coral/orange theme (#f4623a)

## Supported Math Topics

The system automatically classifies questions about:
- **Derivative** - Keywords: derivative, differentiate, d/dx, rate of change
- **Solve** - Keywords: solve, solution, equation
- **Integral** - Keywords: integral, antiderivative, integrate, ∫
- **Quadratic** - Keywords: quadratic, quadratic formula, discriminant
- **Limit** - Keywords: limit, approaches, lim
- **Algebra** - Keywords: algebra, algebraic, variable
- **Geometry** - Keywords: geometry, geometric, shape, triangle, circle
- **Trigonometry** - Keywords: trigonometry, trigonometric, sin, cos, tan

## Troubleshooting

**CORS Error**: If you get CORS errors, make sure:
- Backend is running on `http://localhost:5000`
- Frontend is running on a different port or domain

**Connection Refused**: Make sure the Flask backend is running before opening the frontend.

**Python Module Not Found**: Run `pip install -r requirements.txt` again to ensure all dependencies are installed.

## Deploy To Render

This repo now includes:
- `render.yaml` for Render Blueprint setup
- `backend/Dockerfile` for the Flask + Node runtime

### 1. Create Service On Render

1. Push this repo to GitHub.
2. In Render, click **New +** > **Blueprint**.
3. Connect your GitHub repo and select this repository.
4. Render will detect `render.yaml` and create the web service.

### 2. Set Environment Variables In Render

In Render service settings, confirm these values:
- `FLASK_SECRET_KEY` (already auto-generated by `render.yaml`)
- `FLASK_DEBUG=false`
- `CLOUD_LLM_BASE_URL=https://text.pollinations.ai/openai`
- `CLOUD_LLM_MODEL=openai`

### 3. Deploy Updates

- Render will auto-deploy on new commits if your service has **Auto-Deploy** enabled.
- You can also trigger a manual deploy from the Render dashboard.

### 4. Notes

- The app uses SQLite (`backend/database/app.db`). On Render free web services, filesystem is ephemeral, so DB changes can reset on restart/redeploy.
- For persistent production data, move to a managed database (for example Render Postgres).
